# Лабораторная работа 3

## Задание

Реализовать функцию `difference(arr1, arr2)`, которая возвращает массив элементов из `arr1`, которых нет в `arr2`.

## Реализация

Элементы `arr2` кладутся в `Set` для быстрого поиска. Затем `arr1` фильтруется: остаются только элементы, отсутствующие в этом сете.
